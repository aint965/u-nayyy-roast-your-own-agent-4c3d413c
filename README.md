Entry for the [Roast Your Own Agent](https://make.fun/bounty/u-nayyy-roast-your-own-agent-4c3d413c) competition on make.fun.

`main.ts` writes a single roast line to `/output/entry.txt`: our own agent vetted nine free mints, passed every safety check, then held all nine because its wallet holds only 0.00003408 BNB — below the gas needed to claim them. It does careful due diligence on free money it cannot afford to pick up.

Run it with `node main.ts` (Node 22). Set `OUTPUT_DIR` to write elsewhere for local testing.
